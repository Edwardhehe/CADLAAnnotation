# LA批注 v0.5.2

同时支持 AutoCAD 与 ZWCAD 的本地批注插件，无需登录或联网。两种宿主共用同一套源码、DWG 数据格式、界面和命令。

---

## 安装与加载

### 1. 获取 DLL

从 GitHub Releases 下载 `LAAnnotation-v0.5.2.zip` 并完整解压，再按 CAD 宿主选择 DLL：

| CAD 宿主 | DLL |
|---|---|
| AutoCAD 2015~2024 | `AutoCAD/LAAnnotation.AutoCAD.dll` |
| AutoCAD 2025~2027 | `AutoCAD2025/LAAnnotation.AutoCAD2025.dll` |
| 中望 ZWCAD 2025~2026 | `ZWCAD/LAAnnotation.ZWCAD.dll` |

**注意**：三个 DLL 不可混用，请严格按 CAD 宿主和版本选择；DLL 同目录内的依赖文件也必须保留。

### 2. 加载插件

在 CAD 命令行执行：
```
NETLOAD
```
在弹出的文件对话框中选中对应的 DLL。

### 3. 设置自动加载（可选）

首次 NETLOAD 后，在菜单栏 **LA批注 → 设置自动加载** 点击一次即可。之后每次启动该 CAD，插件会自动加载。再次点击该菜单项可关闭自动加载。

> 原理：在当前用户注册表中写入启动加载项。ZWCAD 与 AutoCAD 各自独立配置。

## 快速上手

### 画第一条批注

1. 命令行输入 `LA_PZ_NOTE`（或菜单栏 **LA批注 → 绘制批注**）
2. 在弹出的面板中确认专业、批注人、外形等参数，点击 **开始批注**
3. 在图纸上依次操作：
   - **点击第一个角点** → 移动鼠标确定云线范围 → **点击第二个角点**
   - 云线即时代在预览——此时 **移动鼠标定位文字框** → **点击确认位置**
   - 弹出批注内容窗口 → 填写内容 → **确定**
4. 完成！云线、文字、边框、引线会组成一个编组同时落图。

### 更多操作

| 操作 | 方法 |
|---|---|
| 编辑内容 | 双击批注任意部分，或 `LA_PZ_EDIT` |
| 移动文字框 | `LA_PZ_MOVE`，选中批注后拖拽文字框位置 |
| 删除批注 | `LA_PZ_DELETE`；或在批注列表中右键 → 删除 |
| 仅画云线 | 在面板中勾选"仅绘云线"再开始，或 `LA_PZ_CLOUD` |
| 查看/搜索批注 | `LA_PZ_LIST` 打开批注列表，双击条目可缩放定位 |
| 批注汇总 | `LA_PZ_SUMMARY`，框选批注后点击汇总表位置，绘制日期+内容汇总表并引线指向各批注框 |
| 导出Word | `LA_PZ_WORD`，框选或全部导出，每条批注生成"时间+云线范围截图+批注文字" |

## 批注类型

### 矩形（默认）

拖拽两个角点确定云线范围，支持外形切换为 **矩形**、**菱形** 或 **椭圆**。

### PL 线（折线）

连续点击折线顶点，**至少 3 个不同、不共线、不自交的点**。达到 3 点后按回车/空格完成，Esc 取消。可画出任意闭合多边形云线（最多 400 个折点）。

### 多对一批注

在面板中选择"多对一批注"模式后开始：
1. 连续绘制多个云线范围（与矩形的两角点方式相同）
2. 每个云线完成后立即显示在图上
3. 在下一个区域的第一个角点提示时 **按回车/空格** 结束区域选择
4. 统一定位文字框、填写内容
5. 所有云线共用同一组文字和编号，每条均有独立引线

## 面板与设置

### 快捷设置（面板直接可调）

| 设置项 | 说明 |
|---|---|
| 专业 | 下拉选择或自行输入 |
| 批注人 | 默认为当前 Windows 用户名 |
| 外形 | 矩形 / 菱形 / 椭圆（仅云线非 PL 时生效） |
| 云线样式 | 等宽（均匀弧瓣）/ 渐变（交替大小弧瓣） |
| 角色 | 批注人 / 校审人 / 回复人 |
| 自动编号 | 开启后按 LA-001、LA-002… 自动递增 |
| 连续批注 | 一次完成后不关闭面板，自动开始下一条 |
| 仅绘云线 | 只画云线，不生成文字、边框和引线 |

> **关键规则**：面板修改在点击"开始批注"时才生效并持久化。一次绘制过程中的所有交互都使用同一次开始的设置快照，不会因中途改面板而变。

### 完整设置（"完整设置…"按钮）

| 分类 | 设置项 |
|---|---|
| 云线 | 半径、线宽、云线自适应、比例 |
| 文字 | 正文字高、首行字高、次行字高、字体自适应、自适应百分比 |
| 样式 | 文字样式（选择图中已有的样式名）、固定宽度 |
| 颜色 | 统一颜色 / 分项颜色（云线、引线、文字、框、回复、通过、对勾） |
| 图层 | 图层名称、附加日期、附加姓名、连接符、是否打印 |
| 人员 | 默认批注人、默认专业、默认角色 |
| 行为 | 自动关闭正交/捕捉、双击编辑、指北规则、自动编号、连续批注 |

设置保存在 `%APPDATA%\LAAnnotation\settings.xml`，全局生效。

## 交互预览

| 阶段 | 预览内容 |
|---|---|
| 矩形区域 | 拖拽第二角点时实时显示云线形状 |
| 多对一区域 | 所有已确定云线持续显示，当前区域实时预览 |
| PL 折线 | 每点随动预览折线路径；可形成有效多边形时显示闭合云线 |
| 文字框定位 | 实时显示云线 + 文字占位框 + 引线 |
| 移动文字框 | 实时预览新位置，按 Esc 取消不修改图纸 |

## 所有命令一览

| 命令 | 功能 |
|---|---|
| `LA_PZ_NOTE` | 打开批注面板 |
| `LA_PZ_CLOUD` | 仅绘制云线范围 |
| `LA_PZ_EDIT` | 编辑选中的批注 |
| `LA_PZ_MOVE` | 移动批注文字框、文字和引线末端 |
| `LA_PZ_DELETE` | 删除整条批注 |
| `LA_PZ_LIST` | 打开批注列表面板 |
| `LA_PZ_SUMMARY` | 框选批注后绘制日期+内容汇总表，并从各批注框引线指向表位 |
| `LA_PZ_WORD` | 导出批注到 Word（时间/云线截图/批注文字），支持框选或全部 |
| `LA_PZ_SETTINGS` | 打开完整设置窗口 |
| `LA_PZ_AUTOLOAD` | 切换当前 CAD 的启动自动加载 |
| `LA_PZ_MENU` | 重建顶部"LA批注"菜单 |

## 杂项

- **双击编辑**：双击批注的云线、引线、文字或边框即可编辑；插件会临时抑制 CAD 快捷特性并在编辑结束后恢复用户原设置。若宿主仍存在原生双击冲突，可使用 `LA_PZ_EDIT`
- **日志**：`%APPDATA%\LAAnnotation\Logs\LAAnnotation.log`
- **数据存储**：批注数据和编号记录在 DWG 文件的 Group 扩展字典中，COPY 后 UUID 暂不自动重新编号
