# LA批注

当前测试版本：v0.3.3。

同时支持 AutoCAD 与 ZWCAD 的本地批注插件。两种宿主共用同一套业务源码、DWG 数据格式、界面和命令，无需登录或联网。

## 构建与加载

1. 在 PowerShell 执行 `./build.ps1`。
2. 按宿主选择 DLL：
   - ZWCAD 2025：`bin/v0.3.3/ZWCAD/LAAnnotation.ZWCAD.dll`
   - AutoCAD 2019+：`bin/v0.3.3/AutoCAD/LAAnnotation.AutoCAD.dll`
3. 在对应 CAD 中执行 `NETLOAD` 加载。不要在 AutoCAD 中加载 ZWCAD DLL，反之亦然。

## 命令

- `LA_PZ_NOTE`：打开批注面板，创建单区域或多对一批注；
- `LA_PZ_CLOUD`：仅绘制云线；
- `LA_PZ_EDIT`：选择并编辑批注；
- `LA_PZ_MOVE`：移动批注文字框、文字及引线末端，云线保持原位；
- `LA_PZ_SETTINGS`：设置图层、颜色、文字和云线尺寸；
- `LA_PZ_AUTOLOAD`：切换当前 CAD 宿主的启动自动加载；
- `LA_PZ_DELETE`：删除整条批注；
- `LA_PZ_LIST`：查看当前图纸的批注列表并双击定位；
- `LA_PZ_MENU`：创建或恢复顶部“LA批注”菜单。

插件加载后会自动尝试在 CAD 顶部菜单栏创建“LA批注”菜单。如果菜单栏被隐藏，可先把 CAD 的 `MENUBAR` 设置为 `1`，再运行 `LA_PZ_MENU`。菜单中的“设置自动加载”是开关：首次执行会把当前宿主和当前 DLL 路径写入当前用户注册表，再次执行会关闭并清理该注册项。ZWCAD 与 AutoCAD 分别配置，不会把一个宿主的 DLL 注册给另一个宿主。

“移动批注”只平移文字框和文字，并调整每条引线的文字框端点；云线端锚点及云线本身保持原位。移动过程中会实时预览，按 Esc 可取消且不修改图纸。

执行 `LA_PZ_NOTE` 后先在面板中选择模式和参数，再单击“开始批注”。完整批注的顺序统一为：先指定云线或 PL 范围，再通过占位框和引线预览确认批注框位置，最后填写批注内容并直接落图。最终文字框保持已确认的左下锚点，根据实际内容向右上扩展并重新连接引线。多对一批注会连续选择多个云线范围，在下一个范围的第一个角点提示时按回车或空格结束，然后统一确认共用批注框位置。取消时不会遗留临时云线，也不会占用编号。

批注面板中的快速设置不会随输入实时写入或影响正在进行的绘制；只有点击“开始批注”时才一次性应用。连续批注始终沿用本次开始时的设置快照。

从 v0.3.0 开始，第二角点移动过程中会通过 DrawJig 实时预览云线；当前版本的完整批注在填写正文前以占位框实时预览标注引线和位置，正文确认后从该锚点生成实际文字框。十字点也会在确认前预览。按 Esc 取消不会写入任何临时图元。云线自适应按每个云线自身尺寸计算弧瓣半径、间距和线宽；多对一批注的各云线分别适配，不受云线之间距离影响。矩形和菱形使用独立的框选云线算法，每边至少 4 瓣，总顶点不超过 400。

PL 云线至少需要三个不同且不共线的折点，回车完成、Esc 取消。PL 使用独立的闭合多边形云线算法，重复折点、自交边界和零面积区域会被拒绝；矩形、菱形、椭圆及 UCS 矩形不进入 PL 校验。

创建、编辑、设置界面已全部迁移为标准 XAML WPF，不再引用 WinForms。源码结构为 `Views/AnnotationWindow.xaml(.cs)`、`Views/SettingsWindow.xaml(.cs)` 和 `Themes/LATheme.xaml`。

设置窗口包含外形（矩形/菱形/椭圆）、云线样式、半径与线宽、自适应与比例、分行字高、人员角色、固定宽度、图层与文字样式、分项颜色、日期/姓名图层规则、连接符、打印、正交/捕捉恢复及双击编辑。“已回复”和“已完成”状态分别使用回复颜色和通过颜色；截屏背景与审批标记在当前版本中明确标为预留。文字框按 MText 实际排版尺寸生成，修改内容后会同步调整边框并重新连接引线。

批注创建后，双击云线、引线、文字或文字框会尝试打开编辑窗口。若当前 CAD 的原生双击行为发生冲突，请使用 `LA_PZ_EDIT`。

设置保存在 `%APPDATA%\LAAnnotation\settings.xml`；完整批注数据保存在 DWG 的 Group 扩展字典中。

启用“字体自适应”后，交互预览按当前 CAD 视图高度估算，最终批注按云线自身对角线和“字高占云线 %”计算实际字高；多对一的共用文字按各云线对角线的中位数计算，不受区域间距影响。启用“云线自适应”后，每个云线的半径与线宽均按自身尺寸计算。固定字高、半径和线宽输入会在对应自适应开启时禁用，取消自适应后恢复。每条批注会保存共享文字的实际绘制尺寸，之后编辑不会因全局设置变化而突然缩放。

运行日志位于 `%APPDATA%\LAAnnotation\Logs\LAAnnotation.log`。

## 第一版已知限制

- COPY 会复制批注 UUID，尚未自动重新编号；
- 暂不提供 Excel 导出和图片批注；
- 双击行为需要在实际 ZWCAD 环境中验证与其他插件的兼容性。
