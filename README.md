# GM批注 v1.0.0

同时支持 AutoCAD 与 ZWCAD 的本地批注插件，无需登录或联网。两种宿主共用同一套源码、DWG 数据格式、界面和命令。

---

## 安装与加载

### 1. 获取 DLL

从 Releases 页面下载最新版本的 `GMAnnotation-vX.Y.Z.zip`（X.Y.Z 为版本号）并完整解压，再按 CAD 宿主选择 DLL：

- GitHub：<https://github.com/Edwardhehe/CADLAAnnotation/releases>
- Gitee（国内访问更快）：<https://gitee.com/Edwardhehe/CADLAAnnotation/releases>

本文档对应源码版本 **v1.0.0**（「关于」窗口 `GM_PZ_ABOUT` 显示的版本号以实际加载的 DLL 为准）。

| CAD 宿主 | DLL |
|---|---|
| AutoCAD 2015~2024 | `bin-acad/GMAnnotation.AutoCAD.dll` |
| AutoCAD 2025~2027 | `bin-acad2025-2027/GMAnnotation.AutoCAD2025.dll` |
| 中望 ZWCAD 2025~2026 | `bin/GMAnnotation.ZWCAD.dll` |

**注意**：三个 DLL 不可混用，请严格按 CAD 宿主和版本选择；DLL 同目录内的依赖文件也必须保留。

### 2. 加载插件

在 CAD 命令行执行：
```
NETLOAD
```
在弹出的文件对话框中选中对应的 DLL。

### 3. 安装自动加载（可选）

首次 NETLOAD 后，在菜单栏 **GM批注 → 安装自动加载**（`GM_PZ_INSTALL_AUTOLOAD`）点击一次即可，之后每次启动该 CAD 都会自动加载插件。
要取消，点 **GM批注 → 卸载自动加载**（`GM_PZ_UNINSTALL_AUTOLOAD`）。命令行的 `GM_PZ_AUTOLOAD` 是二者的切换：已安装就卸载，未安装就安装。

> 原理：在当前用户注册表中写入启动加载项。ZWCAD 与 AutoCAD 各自独立配置。

## 快速上手

### 画第一条批注

1. 点击 CAD 工具栏 **GM批注** 上的单字键 **批**（或命令行输入 `GM_PZ_DRAW`）
2. 在图纸上依次操作：
   - **点击第一个角点** → 移动鼠标确定云线范围 → **点击第二个角点**
   - 云线即时预览——此时 **移动鼠标定位文字框** → **点击确认位置**
   - 弹出批注内容窗口 → 填写内容 → **确定**
3. 完成！云线、文字、边框、引线会组成一个编组同时落图。

> 单字键 **批** 是"绘制"：不再弹出批注面板，直接用当前设置进入选点流程。
> 需要临时改类型/形式/参数时，走菜单 **GM批注 → 绘制批注（面板）**（`GM_PZ_NOTE`）：它会打开批注面板并**立即按面板当前设置开始一条批注**（不用再点"开始批注"）；面板保持打开，改完设置后点"开始批注"即按新设置继续。

### 工具栏

`GM批注` 工具栏随插件加载自动创建（停在 CAD 顶部工具栏区，位置可拖）：

| 单字键 | 命令 | 作用 |
|---|---|---|
| 批 | `GM_PZ_DRAW` | 绘制批注（**不弹批注面板**） |
| 移 / 编 / 删 | `GM_PZ_MOVE` / `GM_PZ_EDIT` / `GM_PZ_DELETE` | 移动文字框 / 编辑 / 删除 |
| 隐 / 显 | `GM_PZ_HIDE` / `GM_PZ_SHOW` | 隐藏 / 显示批注 |
| 合 / 滤 | `GM_PZ_MERGE` / `GM_PZ_FILTER` | 合并内容完全相同的批注 / 按内容过滤显示 |
| 刷 | `GM_PZ_FORMAT` | 格式刷：选源批注 → 调样式对话框 → 连续刷其他批注 |
| 汇 / 出 / 入 | `GM_PZ_SUMMARY` / `GM_PZ_EXPORT` / `GM_PZ_IMPORT` | 汇总 / 导出 / 导入 |
| 例 | `GM_PZ_LEGEND` | 批注清单：全图批注生成清单表画在图上（列与批注列表一致；不框选、不画引线） |
| 历 | `GM_PZ_HISTORY` | 批注历史记录（留痕） |

- `GM_PZ_TOOLBAR`：显示/隐藏工具栏（不存在时创建，重复执行会按当前版本重建按钮）；`GM_PZ_TOOLBAR_SHOW` / `GM_PZ_TOOLBAR_HIDE` 分别只显示 / 只隐藏。
- **记住显隐**：点工具栏上的 × 关掉（或在 CAD 工具栏右键菜单里取消勾选）后，下次启动 CAD 保持隐藏；随时输入 **`GMPANEL`**（即 `GM_PZ_TOOLBAR_SHOW`）重新打开。
- **先选后点**：编 / 删 / 移 / 隐 / 显 / 滤 / 刷 / 出 以及菜单里的「增补云线」会使用当前预选的批注，所以这几个按钮的宏**不再带 `^C^C`**（否则 ^C 会先清掉你的选择）。代价是：如果另一个命令还在运行，请先按 Esc 再点这些按钮。其余按钮仍以 `^C^C` 开头，会先取消正在运行的命令。
- 浮动单字快捷栏**已取消**：工具栏是单字按钮的唯一入口。
- 图标由插件现场生成（单字画成白底深蓝的 BMP，观感与原快捷栏按钮一致），缓存在 `%APPDATA%\GMAnnotation\icons`（`tb_v3_<字的码位>_16.bmp` / `_32.bmp`：小/大图标各一份，按字的码位命名，增删按钮不会错字；改画风只需升版本号前缀）。图标生成失败只是按钮没图标，不影响命令。

### 更多操作

| 操作 | 方法 |
|---|---|
| 绘制 | 工具栏 **批** 键 / `GM_PZ_DRAW`：框选范围 → 放文字框 → 填内容，全程不弹批注面板；编号、留痕、入库与面板流程一致 |
| 编辑内容 | 双击批注任意部分，或 `GM_PZ_EDIT`。编辑只改文字内容与内嵌数据：**图层保持原样**；只有「状态」改变时才按状态重设文字颜色（手工改过的颜色在状态不变时保留）。手工改编号与本图其他批注重复时会弹框提醒 |
| 回复批注 | 批注窗口「回复」按钮：在内容末尾追加"分隔线 + 回复:时间 批注人 + 内容:"，可多次回复；回复随批注一起显示在图上 |
| 拾取图号 | 批注窗口「图号」旁的「拾取文字」按钮：在图上点选单行文字 / 多行文字 / **块属性文字**即可填入；点到属性块时自动取其属性，**块里有多个属性文字时以鼠标点中的那一个为准**（点不到具体属性文字时才提示重选），自动去掉「图号：」前缀 |
| 格式刷 | `GM_PZ_FORMAT`（工具栏 **刷** 键）：选一条源批注 → 弹出样式对话框（首行/次行/批注字高、文字样式、云线样式、图层名与云线/引线/文字颜色，已按源批注实测预填）→ 调整后**连续点选**其他批注套用，回车结束。只刷外观，内容/编号不变，支持 UNDO |
| 移动文字框 | `GM_PZ_MOVE`，选中批注后拖拽文字框位置 |
| 删除批注 | `GM_PZ_DELETE`；或在批注列表中右键 → 删除。**预选了多条批注时一次全部删除**（同一条批注的多个部件只算一条），一次 UNDO 全部恢复 |
| 隐藏/显示批注 | `GM_PZ_HIDE` / `GM_PZ_SHOW`，只切换批注自身的可见性，数据仍保留在图内；未预选时作用于全图批注 |
| 合并批注 | `GM_PZ_MERGE`（工具栏 **合**）：把内容完全相同的批注并成一条（保留编号最小者，其余云线/引线并入它，重复的文字与文字框删除）；执行前弹确认框列出要合并的分组 |
| 过滤批注 | `GM_PZ_FILTER`（工具栏 **滤**）：打开「批注过滤」窗口按内容分组，选中一组即只显示这组、隐藏其余；也可以先选中一条批注再执行，直接按它的内容过滤 |
| 刷新批注文字 | `GM_PZ_REFRESH`，按当前"批注框内显示内容"设置重写全图批注版式（旧图套用新版式） |
| 仅画云线 | 在面板中勾选"仅绘云线"再开始，或 `GM_PZ_CLOUD`（可在云线右下角加"框 + 文字"标记，见下文"云线标记"） |
| 增补云线 | `GM_PZ_ADDCLOUD`（菜单「GM批注 → 增补云线」，或先选中一条批注再执行）：连续框选新范围，每条补一条云线和一条连到原文字框的引线；**图层/颜色/线宽照抄原批注，外形/云线样式/弧瓣半径按当前设置**（详见下文）；需在批注所在的空间（模型/布局）里执行；回车/空格结束 |
| 输入建议 | 批注内容框下勾选「输入建议」（默认开）：打字时按「批注历史记录 / 常用批注语 / 知识库条目」实时给出候选，↑↓ 选择、**回车或 Tab 套用**、Esc 关闭，`Ctrl+空格` 手动调出；候选以已输入内容开头时即为**续写** |
| 查看/搜索批注 | `GM_PZ_LIST` 打开批注列表，双击条目可缩放定位；状态为"已完成"的行显示绿色文字，"已回复"的行显示黄色文字 |
| 清理留痕 | 批注历史记录窗口（`GM_PZ_HISTORY`）的"清理"按钮：按当前过滤条件清理留痕（不设过滤即清空全部），清理前自动备份到 `history.json.bak` |
| 清除历史下拉 | 批注窗口「历史」下拉旁的「清除」按钮：清空"最近使用过的批注内容"候选，**不删除**批注历史记录；清除后新批注内容会重新积累 |
| 知识库 | 批注窗口左下「知识库(K)」按钮（或 `GM_PZ_KB`）：两个页签——「知识库条目」（规范条文表：**序号/专业/属性/规范名称/规范编号/条款/内容**）与「常用批注语」。条目表**可直接编辑**（改完自动保存，内容列支持换行），另有新增/刷新/填入内容/导出CSV/导入CSV/删除选中/清空条目；常用批注语支持添加/替换/删除/清空/导出CSV/**导入CSV**。双击一行可把它的「内容」填进批注窗口的内容框 |
| 立即入库 | 批注窗口的「立即入库」勾选**只控制是否写入知识库**：勾上后，创建批注时把该条批注写入知识库——**条目表**里新增/更新一行（只填「专业 + 内容」，规范名称/编号/条款留空待手填）并并入「常用批注语」。**留痕（批注历史记录）不受这个勾选影响，创建/修改/删除等操作始终记录** |
| 批注汇总 | `GM_PZ_SUMMARY`，框选批注后点击汇总表位置，绘制日期+内容汇总表并引线指向各批注框 |
| 批注清单 | `GM_PZ_LEGEND`，**不用框选**，自动取本图全部批注，在指定位置绘制带表头的清单表（**列与批注列表窗口一致**：编号/专业/状态/批注人/角色/日期/内容，**不画引线**），适合放在图签旁 |
| 导出Word | `GM_PZ_WORD`，框选或全部导出，每条批注生成"时间+云线范围截图+批注文字"。截图前先检查目标 docx 能否写入（文件正在 Word 中打开会直接提示，不白截一遍）；**被隐藏的批注会在给它截图时临时显示、截完立即恢复隐藏**（图纸会因此标记为已修改） |

### 知识库条目（规范条文表）

页面里第一列是**序号**（按文件顺序从 1 编号，仅供定位；导出时重排、导入时忽略），业务列为
**专业 / 属性 / 规范名称 / 规范编号 / 条款 / 内容**。表格**可直接编辑**，改完自动保存，不需要点"保存"按钮。

- **导出CSV**：列序与列表完全一致（`序号,专业,属性,规范名称,规范编号,条款,内容`），**导出的文件就是导入模板**——在 Excel 里改完另存为「CSV UTF-8」再导回即可。
- **导入CSV**：表头按名称识别（兼容 `规范名 / 标准名称 / 规范号 / 文件编号 / 条款号 / 条文内容 / 批注内容` 等别名，也容忍空格与 `*`）；**表头识别不到时按上面的顺序逐列解析**。判重规则是 **规范编号 + 条款相同即视为同一条**（更新），两者都空则一律新增；清单里已有的其它条目不会被删掉。
- **编码**：按 UTF-8(BOM) → UTF-8 → GBK → 系统默认 依次尝试，所以 Excel 直接"另存为 CSV"（GBK）也能读，但中文环境更稳的是另存为「CSV UTF-8」。
- **备份**：删除选中 / 清空 / 导入之前都会把整个知识库原样备份到 `%APPDATA%\GMAnnotation\knowledge.json.bak`（只保留最近一次）；表格里直接改这种常规保存不备份。
- **常用批注语导入**：第一行含「常用批注语 / 批注内容 / 内容」表头时取该列，否则取第一列逐行读入，同内容不重复添加。

> 批注窗口的「立即入库」勾选只会写「专业 + 内容」两列（规范名称/编号/条款留空，之后再手工补），与在知识库里直接导入/手工编辑是两条互不冲突的入口。

### 增补云线（一条批注，多个范围）

一条批注需要圈出图上多处位置时用 `GM_PZ_ADDCLOUD`：点选一条既有批注后，连续框选新范围，每框一次就补画一条云线 + 一条从云线连到**原文字框**的引线，回车/空格结束。

**新补的云线按批注设置里的「批注外形 / 云线样式 / 云线半径」生成**（含比例换算与自适应），图层、颜色、线宽仍照抄原批注。
新云线写入**原批注所在的空间**；当前空间与批注所在空间不同时（例如批注在模型空间、你在布局的图纸空间里），命令会提示先切换过去（布局里的模型空间批注可双击进入视口后再增补）。

| 复制项 | 来源 |
|---|---|
| 图层 | 原云线所在图层（原批注图层带日期/人名后缀时也照抄，不会落到"今天"的图层上） |
| 颜色 / 线宽 | 原云线、原引线实体上的实际值（引线粗细单独取，不跟云线混） |
| 外形 / 云线样式 / 弧瓣大小 | 批注设置「外形与云线」页的当前设置（矩形/菱形/椭圆，等宽/渐变） |

> 另一个入口：**编辑批注窗口的「增补云线」按钮**（点「编」打开面板后可见）——窗口先保存已填内容并关闭，在图上连续框选增补（回车结束），随后自动重开窗口继续编辑，已填内容不丢。

### 云线标记（单绘云线右下角的"框 + 文字"）

单绘云线时可以在云线**右下角内侧**自动加一个小标记（例如六边形里写 A），用来给修改处编号。默认关闭。

- **开关与设置**：`GM_PZ_CLOUD` 第一角点提示为 `指定云线范围第一个角点或 [标记开关(M)/标记设置(S)]`：输入 `M` 开/关，输入 `S` 打开"云线标记设置"窗口；改动立即保存并重新提示选点。设置窗口「外形与云线」页底部"云线标记（单绘云线）"也有开关和"标记设置…"按钮（随"保存设置"一起保存）。
- **作用范围**：开启后 `GM_PZ_CLOUD`、面板勾选"仅绘云线"（矩形与 PL）、`GM_PZ_DRAW` 的仅绘云线都会带标记；完整批注（有文字框/引线）不加。
- **设置项**：

| 项 | 默认 | 说明 |
|---|---|---|
| 文字 | A | 记住上次输入；可勾选"每画一个自动递增"（A→B→…→Z→AA，1→2，A9→A10，保留大小写和位数） |
| 字高 | 2.5 mm | 打印尺寸 |
| 框高 | 5 mm | 建议字高 2 倍；小于字高×1.1 时自动放大 |
| 框宽 | 10 mm | 仅长形有效，建议字高 5~10 倍；不小于框高 |
| 形状 | 六边形 | 单字形：圆 / 矩形 / 六边形 / 八边形 / 菱形；长形：椭圆 / 长矩形 / 长六边形 / 长八边形 / 平行四边形 |
| 颜色 | 与云线同色 | 也可指定 ACI 1~255；图层始终跟随云线 |

- **比例**：三个尺寸按打印毫米填写，落图时与批注字高走**同一个换算**（`ResolveEffectiveSettings`）：开了字体自适应就随云线大小按"自适应百分比"缩放；固定比例 1:N 时 ×N；布局图纸空间按 1:1。
- **位置**：标记整体放在云线包络（当前 UCS 下）右下角的内侧，离边留出间距避开弧瓣（渐变云线 1 个云线半径、等宽云线 0.3 个半径，且都不少于 0.3 个框高）；椭圆云线贴着右下 45° 方向的边，菱形云线贴着右下边的中点；PL 云线取折线包络的右下角。旋转 UCS 时标记跟着 UCS 摆正。
- **编组**：框线、文字与云线编成一个匿名组，选中云线即可一起移动/复制/删除。云线比标记还小时照常绘制并在命令行提示。

### 导入到其他 DWG 保持原样式

导出 CSV 会带 5 列图面实测尺寸（**图面字高 / 图面首行字高 / 图面次行字高 / 图面云线半径 / 图面线宽**）；导入到其他 DWG 时按编号新建的批注会**逐条照抄这些实测值**（比例置 1、关自适应、字高弧瓣线宽用实测值），样式与原图保持一致，不会按本机当前设置重算。旧版 CSV 没有这几列也能正常导入（按当前设置生成，历史行为）。

### 导入 CSV 的编码与表头

- **编码自动识别**：UTF-8(BOM) → 严格 UTF-8 → GBK，Excel 中文版直接"另存为 CSV"（GBK）与「CSV UTF-8」都能导入；导入报告末尾会注明识别到的编码。AutoCAD 2025+（.NET 8）也支持 GBK。
- **表头**：既没有「编号」也没有「批注内容」列时直接报错（多半是选错文件），不会导入任何内容；只缺「编号」时全部按新建处理，只缺「批注内容」时已有批注的内容保持不变，报告里都会提示。
- 最稳妥的做法是用本插件导出的 CSV 当模板修改后再导回。

### 导出保留图形坐标 / 导入按原坐标还原

导出 CSV 还带 **8 列放置信息**：**布局 / 云线X1 / 云线Y1 / 云线X2 / 云线Y2 / 文字X / 文字Y / 标高**（全部为 WCS 绝对坐标；云线两角点是云线**顶点**的包络，不含向外鼓出的弧瓣，所以反复导出导入不会越还原越大；文字锚点是文字框左下角，也就是创建时传入的锚点）。

导入时：

- 带坐标的条目（本版导出的 CSV）**默认按原图坐标还原**——连同**布局**一起还原（模型空间的回模型空间，某布局的回该布局；本图没有这个布局时落到当前空间并在报告里提示），落在与原图完全相同的位置，不需要再指定基点；
- 只有一部分行带坐标时，命令行会问 `新建批注位置 [按原图坐标(P)/指定基点(B)] <P>`；
- 没有坐标的行（旧版 CSV、手工编辑删掉了坐标列）仍走老流程：指定基点 → 网格排布；
- 已经存在同编号批注的行只**更新信息、保留图上位置**，不会被坐标搬动。
- 还原到**非当前布局**时按 WCS 构建（不受当前空间的 UCS 影响）。

> 坐标与"图面实测尺寸"配合，才能做到导到别的图纸后**位置 + 样式**都与原图一致。

### 合并批注与按内容过滤

这两件事都以**「批注内容完全一致」**为准（换行归一、去首尾空白后逐字符相等；**日期/批注人/编号不参与判重**——编号本来就各不相同，一旦参与就永远合并不了）。

**合并（`GM_PZ_MERGE` / 工具栏「合」/ 过滤窗口里的按钮）**

1. 先弹确认框，列出检测到的分组（`编号 × 内容摘要`）与将保留/并入的条数；
2. 每组保留**编号最小、且有编组**的那条作主批注；
3. 其余批注的**云线与引线整体并入**主编组（等于把重复的批注变成"一条批注、多个范围"，与"多对一批注"同构）；
   - 引线**指向文字框的那一端**改接到主批注文字框最近的角点（先看它离原文字框更近的是哪端）；
   - 云线/引线的**图层、颜色、线宽统一照抄主批注**——图层名带日期/人名后缀，不统一的话按图层隐藏会漏掉一半实体；
   - 跨布局（模型空间/图纸空间）的批注**不合并**，会在报告里说明；
4. 重复批注的**文字与文字框删除**，编组解散；
5. 留痕：主批注记一条"合并"，被并入的每条记一条"合并删除"。整个操作支持 UNDO。

**过滤（`GM_PZ_FILTER` / 工具栏「滤」）**

- 打开「批注过滤」窗口：按内容分组列出`条数 / 编号 / 内容摘要`，选中一行点「仅显示所选」（或双击该行）→ 图中**只显示这一组**，其余批注全部隐藏；点「显示全部」恢复。
- 窗口里也能直接点「合并批注」，合并后列表自动刷新。
- 若执行命令前**已选中**一条批注，会直接按它的内容过滤，并把对应分组选中。
- 只切**实体可见性**（与隐藏/显示同一机制），不删数据、不改图层；注意「显示全部」会把之前手动隐藏的批注也一起显示出来。

### 批注内容输入建议

批注窗口的内容输入框带实时建议（勾选框「输入建议」控制，默认开，选择会被记住）：

- **语料**：① 批注历史记录里以前写过的批注内容（`history.json`）② 知识库「常用批注语」③ 知识库「规范条文条目」的正文；条目还能按规范名称/编号/条款检索（输入 `GB50007` 或 `地基基础` 也能找到对应条文）。
- **每条候选都带来源标签**（历史 / 常用语 / 条目），条目还显示"规范名称 编号 条款"。
- **匹配规则**：候选以当前已输入内容**开头** → 排最前，套用即"续写"；否则按包含关系与字词重合度排序。候选在**当前行**里匹配，套用时**只替换当前行光标之前那段**，其它行不动。
- **操作**：↑↓ 选择 · 回车 / Tab 套用 · Esc 关闭 · `Ctrl+空格` 手动调出 · 鼠标点击也可套用。正在写长句（当前行超过 14 字且没有可续写候选）时不会弹窗打扰。
- **完全本地**：不联网、不调用任何模型，只做关键词级检索与排序，不会凭空生成新句子；本行没有合适的候选时就安静地不显示，手写完全不受影响。

> 语料改动（知识库/历史）最多 2 秒后反映到候选里；同一文件在 1 秒内按 2 秒窗口读一次，逐键输入不会反复读盘。

### 复制 / 粘贴后的批注与编号

CAD 的 COPY、复制粘贴不会复制批注编组，插件靠每个实体里冗余保存的批注数据识别副本：

- 编辑、删除、移动、增补云线等命令碰到副本时会**自动修复**；`GM_PZ_REPAIR` 可一次修复全图。
- 修复时按"同一空间 + COPY 产生的匿名编组 / 几何上相连"把副本拆成独立的批注（一份副本最多含一个文字和一个文字框）。
- 原批注还在本图时：**原批注保留原编号**，每份副本都会获得**新的批注 Id 和不重复的新编号**（从图中最大编号 + 1 起），并把新编号写回副本文字，命令行/修复报告列出"旧编号 → 新编号"。
- 从别的图纸粘贴过来（本图没有原批注）时：第一份保留原 Id 和编号（编号已被本图占用时才重新编号），其余副本重新编号。
- 编辑批注后，所有部件里的内嵌数据都会同步更新，之后再复制出来的副本内容就是最新的。

### 批注内容长度

批注数据随每个实体保存在 CAD 扩展数据（XData）里，容量有限：编码后上限约 12000 字符，**约合中文 3000 字 / 英文 9000 字**。超出时批注窗口会提示并给出建议的字数上限；超长说明请放到知识库或外部文档中引用。

## 批注类型

### 矩形（默认）

拖拽两个角点确定云线范围，支持外形切换为 **矩形**、**菱形** 或 **椭圆**。

### PL 线（折线）

连续点击折线顶点，**至少 3 个不同、不共线、不自交的点**。达到 3 点后按回车/空格完成，Esc 取消。可画出任意闭合多边形云线（最多 400 个折点）。

### 多对一批注

在面板中选择"多对一批注"模式后开始：
1. 连续绘制多个云线范围（与矩形的两角点方式相同）
2. 每个云线完成后立即显示在图上
3. 在下一个区域的第一个角点提示时 **按回车/空格** 结束区域选择
4. 统一定位文字框、填写内容
5. 所有云线共用同一组文字和编号，每条均有独立引线

| 分类 | 设置项 |
|---|---|
| 云线 | 半径(mm)、线宽(mm)、云线自适应 |
| 文字 | 正文字高(mm)、首行字高(mm)、次行字高(mm)、字体自适应、自适应百分比、**比例选型** |

| 图层 | 图层名称、附加日期、附加姓名、连接符、是否打印 |

| 批注框内显示 | 首行固定为「日期　专业　批注人」且保持同一行；批注内容必显；图号、状态可勾选。编号不显示在图内（仍用于批注列表与导出/导入匹配） |

设置保存在 `%APPDATA%\GMAnnotation\settings.xml`，全局生效。批注面板只保存面板上的那几项（以及下一个编号），不会覆盖设置窗口里改过的其他项。

## 杂项

- **双击编辑**：双击批注的云线、引线、文字或边框即可编辑；插件会临时关闭 CAD 快捷特性（QPMODE）与原生双击编辑（DBLCLKEDIT），编辑结束后恢复用户原设置。原值同时记在 `settings.xml`，万一 CAD 在编辑期间崩溃，下次加载插件时自动恢复（只在它们仍处于关闭状态时恢复）。若宿主仍存在原生双击冲突，可使用 `GM_PZ_EDIT`
- **预选**：编辑/移动/增补云线/格式刷/过滤会从预选集中挑出第一条批注（预选里混有其他对象也可以）；删除/隐藏/显示/导出作用于预选中的全部批注
- **批注列表**：执行 U / UNDO / REDO / MREDO / OOPS 后自动刷新；列表、汇总、清单、CSV、Word 都按编号**自然排序**（GM-9 在 GM-10 之前）
- **日志**：`%APPDATA%\GMAnnotation\Logs\GMAnnotation.log`
- **数据存储**：批注数据和编号记录在 DWG 文件的 Group 扩展字典中，并冗余保存在每个实体的 XData 里（用于识别复制出来的副本）
- **本机数据文件**（`%APPDATA%\GMAnnotation\`）：`settings.xml` 设置 · `history.json` **批注历史记录**（留痕）· `knowledge.json` **知识库**（规范条文条目 + 常用批注语）· `drawingnos.json` 图号记忆（标准 JSON，路径不区分大小写）· `recentcontents.cleared` "历史下拉"的清除标记。其中**批注历史记录与知识库是两套独立体系**：各自的查询、导出、删除、清空互不影响
- **多进程安全**：同时开着 AutoCAD 与 ZWCAD（或两个 CAD）时，上述文件的读-改-写通过系统互斥锁串行，写入采用"临时文件 + 原子替换"，不会互相覆盖或写出半截文件；读取失败时不会回写（不会把读坏的文件当空文件保存）。`drawingnos.json` 损坏时先备份为 `drawingnos.json.corrupt-时间.bak`，再保留能识别的记录

## 已知限制

- 暂不提供 Excel 导出和图片批注
- 批注内容有长度上限（约中文 3000 字，见上文）
- 依赖预选集的工具栏按钮/菜单项不带 `^C^C`：有其他命令正在运行时需先按 Esc（中望 CAD 对菜单宏 DIESEL 条件表达式的支持不确定，故未采用 AutoCAD 专用的条件宏写法）
- 增补云线必须在批注所在的空间中执行；跨空间（模型 ↔ 布局）的批注不参与合并
- 复制修复按几何相连判断副本归属：两份副本互相重叠/紧贴时可能被并成一组，可用 `GM_PZ_REPAIR` 报告核对
- 云线标记不带 GM 批注数据：批注列表/导出/`GM_PZ_DELETE` 等不识别它，靠编组与云线一起选中；拖动预览中不显示标记；凹形 PL 云线的包络右下角可能落在云线外
- 导出 Word 时会临时显示被隐藏的批注再恢复，图纸会被标记为已修改（可直接关闭不保存，或保存，内容不变）
