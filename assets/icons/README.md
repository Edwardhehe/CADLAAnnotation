# GM 批注图标（方案 A）

蓝底云线 + 六边形角标「A」图标资源，用于 CAD 批注软件工具栏 / 窗口图标。

## 文件

| 文件 | 说明 |
|------|------|
| `gm-annotation.png` | 主图 256×256 PNG（与 `-256` 相同） |
| `gm-annotation-16.png` … `-512.png` | 多尺寸 PNG |
| `gm-annotation.ico` | 多尺寸 ICO（含 16 / 32 / 48 / 256） |

## 尺寸

PNG：16、24、32、48、64、128、256、512  
ICO：16、32、48、256

## 来源

方案 A 选定稿；已裁成正方形并去除多余白边，圆角外为透明。

## 注意

本目录仅资源文件，暂未接入 WPF / 工具栏界面代码。
